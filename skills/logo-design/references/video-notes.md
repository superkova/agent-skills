# Timestamped notes for the logo-design skill

Source: [The ONLY Logo Design Guide You Need for 2027 — Satori Graphics](https://www.youtube.com/watch?v=Ad0hBv_VMO0). Runtime: 20:40. Reviewed on 8 November 2026 using the available English (United Kingdom) captions.

These are selective paraphrased notes, not a verbatim transcript. Timestamps locate the relevant discussion. The captions vary in their spelling of example brand names, so those names are not relied on here. The sponsorship segment at approximately 8:25–9:40 is omitted.

| Video location | Reusable lesson |
| --- | --- |
| [0:14–1:37](https://www.youtube.com/watch?v=Ad0hBv_VMO0&t=14s) | Consider how a mark's distinctive geometry could support the wider identity. Try an application during concept development, such as a photographic crop or motion reveal, to discover whether its character travels naturally. |
| [1:49–4:40](https://www.youtube.com/watch?v=Ad0hBv_VMO0&t=109s) | Broaden ideation beyond the first industry association. Explore the offering, its delivery, and its customer benefit. Include typographic directions. Translate vague brand adjectives into audience meaning, differentiation, and placement requirements. |
| [4:50–6:17](https://www.youtube.com/watch?v=Ad0hBv_VMO0&t=290s) | Compare concepts in consistent conditions and in a relevant application. Examine the smallest important use early. Check both usability and whether the mark conveys the intended character. |
| [6:26–8:18](https://www.youtube.com/watch?v=Ad0hBv_VMO0&t=386s) | Give each logo version a practical purpose. Test full and compact versions inside real placements. For animation, let the shape suggest movement while the brand's tone informs pacing and energy. |
| [9:41–10:51](https://www.youtube.com/watch?v=Ad0hBv_VMO0&t=581s) | Compare against competitors fairly. Use brief exposure and delayed recognition to investigate confusion. Gather unprompted impressions before explaining the intended meaning. |
| [11:01–12:20](https://www.youtube.com/watch?v=Ad0hBv_VMO0&t=661s) | Organize handover around the client's practical tasks. Make file selection clear, show intended uses, and identify physical applications that need sampling. |
| [12:31–14:54](https://www.youtube.com/watch?v=Ad0hBv_VMO0&t=751s) | Start with relevant environments and category research before detailed sketching. Express a focused idea and simplify it rather than accumulating decorative detail. |
| [15:01–16:34](https://www.youtube.com/watch?v=Ad0hBv_VMO0&t=901s) | Inspect the vector skeleton. Redundant anchors and uneven curve tension can undermine finish, scaling, and later editing. Clean the paths deliberately. |
| [16:40–18:02](https://www.youtube.com/watch?v=Ad0hBv_VMO0&t=1000s) | Explore the brand's vocabulary and a short sample message to clarify its voice. Use that tone to judge whether the visual character fits. |
| [18:10–20:18](https://www.youtube.com/watch?v=Ad0hBv_VMO0&t=1090s) | A category comparison board can reveal interchangeable marks. Seek a recognizable position through proportion, typography, or form while retaining relevance to the brief. |

## Adaptation into the skill

The skill reorganizes these ideas into a working process rather than reproducing the video's sequence. Instructions about editable SVGs, tool choice, truthful reporting of user tests, and inspecting exported files are practical additions for agent-assisted execution. They should not be attributed to the presenter as direct statements. The video supplies design heuristics; successful recognition and production performance still require testing on the actual project.
